# Smart Campus Event Management System

## Project Overview
A web-based campus event management system
developed to simplify event organization,
student registration, attendance tracking,
and participation analytics.

## Technology Stack
- Frontend: React.js, Vite
- Backend: Java, Spring Boot
- Database: SQLite
- ORM: Spring Data JPA, Hibernate
- API Communication: Axios

## Features
1. Event creation and management
2. Student registration and management
3. Event capacity validation
4. Duplicate registration prevention
5. Attendance tracking
6. Dashboard statistics
7. Event and department analytics

## How to Run

### Backend
Open a terminal in the backend folder:

.\mvnw.cmd spring-boot:run

Backend: http://localhost:8080

### Frontend
Open another terminal in the frontend folder:

npm install
npm run dev

Frontend: http://localhost:5173

## Database
SQLite stores events, students,
registrations, and attendance records.
